# Tributary — Architectural & Product Decisions Log

One line per significant decision with date, adhering to the project working agreements.

- **2026-10-01**: Project renamed from OmniGit to **Tributary**; licensed under **MIT** per competition handoff plan.
- **2026-10-01**: Thesis locked: "GitHub coordinates humans. Tributary coordinates agents." Focusing on: (1) claim-time conflict prevention, (2) attestation-based verification, and (3) epistemic memory crystallization.
- **2026-10-01**: Technology stack pinned to Cloudflare Workers (TypeScript + Hono), Cloudflare Artifacts (`ARTIFACTS` binding), and Durable Objects (`ChangeProposal` DO).
- **2026-10-01**: Scope guardrails enforced: excluded full AST semantic merger, full IAM broker, and multi-gate complexity in v1; prioritizing single `test` gate, claims, and CAS merge.
- **2026-10-01**: Gate execution strategy: implemented HMAC-signed attestation verification protocol; simulated in Node unit test suite pending Cloudflare API token.
- **2026-10-01**: Demo victim repository chosen: `demo-shop` with `src/session.ts` shared between `src/auth/` and `src/billing/` as the collision trap.
- **2026-10-02**: Public GitHub repository connected (`Mocker/tributary`) and branch `main` pushed to remote origin.
- **2026-10-02**: Added global claims & proposals registry endpoints (`GET /v1/claims`, `GET /v1/proposals`) to support real-time reactive Radar UI polling.
- **2026-10-02**: Embedded 1-click interactive simulation runner (`POST /v1/admin/simulate`) directly into the Radar dashboard header for judge self-service walkthroughs.
- **2026-10-07**: Removed the legacy inline-HTML radar page from `src/index.ts` — it failed `tsc` (unescaped backticks inside the outer template literal, so wrangler could never build it). Radar is now the React + Vite app in `ui/`, built to `ui/dist` and served via wrangler `[assets]`; `npm run build:ui` builds it, wired into wrangler's `build.command`.
- **2026-10-07**: Added missing PLAN.md §6 routes: `GET /v1/interventions` and `POST /v1/interventions/:id/resolve`. Semantics: approve supersedes the conflicting claim (yielding the path to the blocked agent, which can re-claim); reject upholds the existing claim (blocked agent must narrow).
- **2026-10-07**: Claim rejections (409) and intervention resolutions now broadcast onto the proposal's SSE context bus (new internal DO route `POST /broadcast`); the radar surfaces the one-sentence rejection reason live as a prominent banner.
- **2026-10-07**: Fixed demo-script Act 5 — the fake fork-latency timing loop (random sleeps presented as measured numbers) replaced with an explicitly-labeled projection from the Phase 0 spike notes; live measurement still pending the Cloudflare token.
- **2026-10-07**: Fixed `ArtifactsClient.spawnMicroFork` to use the repo-handle fork primitive (`repo.fork(name)`) per the plan's §4 API surface; removed the unverified "zero-copy" claim from its docstring per the plan's honesty rule.
- **2026-10-07**: Folded the 2026-10-03 "Guard Gate" brief into `docs/BUILD_PLAN.md` §4: decision-model choice (OpenAI Decisions API disqualified — preview-gated; AWS Decider 2B = independence pick, Apache 2.0; Cloudflare Clef flash = politics pick; call = Clef for the story, Decider for the safety) + Agent Access Model vocabulary; v1 scope unchanged (decision model is a future-gate extension point).
- **2026-10-07**: Baseline health restored — tsconfig `types` now includes `node` (test files failed typecheck); `tsc` clean, 11/11 unit tests pass, 6-act demo simulation runs end-to-end locally.
- **2026-10-09**: Added machine-checked merge-gate invariants (`test/merge-invariants.test.ts`, z3-solver devDependency): Z3 proves each PLAN.md §7 merge guard (active claim, passing gate attestations, CAS) individually necessary for `merged`; differential test ties the model to `evaluateMergeGate` on all 8 guard combinations. Demo framing: machine-checked model, not end-to-end formal verification.
- **2026-10-11**: Added interactive Judge Quick Tour and curl snippet clipboard panel to Radar dashboard (`ui/`); documented Agent Ecosystem integration patterns (smart-HTTP + scoped tokens for external agents) in README; added comprehensive competition review and rubric alignment analysis in `docs/CLOUDFLARE_CHALLENGE_REVIEW.md`.
- **2026-10-12**: Implemented native Model Context Protocol (MCP) server (`src/mcp/server.ts`, `@modelcontextprotocol/sdk`) exposing 10 agent coordination tools over stdio for Claude Desktop, Cursor, Pi, and Aider; published whitepaper in `docs/why-cloudflare-artifacts.md` analyzing why Artifacts is the only viable edge substrate for multi-agent code swarms.
